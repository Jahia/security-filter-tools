Changed how Jahia reads the scopes, IP address and referer lists that a token carries.

Jahia refuses a token whose list is written as a single value instead of a list. A refused token grants no access, so a call that used it receives the response of a caller with no token. You are affected if you sign your own tokens outside the GraphQL token mutation. Check whether any of those three claims is written as a single value. Write each one as a list of values, then reissue the affected tokens. Jahia writes the name of the claim it could not read to the log.
