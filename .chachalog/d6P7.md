Changed how Jahia reads the scopes, IP address and referer lists that a token carries. (#95)

Jahia refuses a token whose list is written as a single value, and one whose list holds an empty entry. A refused token grants no access, so a call that used it now receives the response of a caller with no token. You are affected if you sign your own tokens outside the GraphQL token mutation. Check whether any of those three lists is written as a single value. Write each one as a list of values, then reissue the affected tokens. Jahia names the list it could not read in its debug log.
